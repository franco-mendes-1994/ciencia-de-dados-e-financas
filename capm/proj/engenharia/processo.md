# Processo de software

O processo de seftware será o [openUP]() que é um processo iterativo e incremental de desenvolvimento. Na nossa implementação particular do processo, haverá, ao menos, três iterações onde cada uma delas será composta das seguintes fases:

1. Engenharia de requisitos
2. Projeto de software
3. Implementação e testes unitários
4. Testes de integração e implantação
